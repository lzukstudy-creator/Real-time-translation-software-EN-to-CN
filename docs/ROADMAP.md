# 课译功能路线图（2026-11-17 整理）

参考：Notta / Otter（课堂标记重点、多格式导出、全文搜索）、auto-caption（字幕样式、SRT/JSON 导出）、
v2s / OST（macOS 字幕浮窗、译文在上）、LiveTranslate / OST（同时收系统声音与麦克风）、apirak/subtitle（大字号置顶显示）。

| 优先级 | 功能 | 价值 | 成本 | 状态 |
|---|---|---|---|---|
| P0 | 菜单栏与快捷键 | ⌘Q/⌘C/⌘F 等此前不可用 | 低 | ✅ 完成 |
| P1 | 标记重点（★） | 复习时快速找到老师强调的内容 | 低 | ✅ 完成 |
| P1 | 字幕内查找（⌘F） | 快速定位某个词 | 低 | ✅ 完成 |
| P2 | 导出 SRT / Markdown 学习笔记 | 放进笔记软件、配合录像 | 中 | ✅ 完成 |
| P2 | 显示顺序：中文在上 / 仅中文 | 看中文为主时更顺眼 | 低 | 待做 |
| P3 | 系统声音输入（网课、视频、Zoom），ScreenCaptureKit | 线上课也能用 | 中高 | 待做 |
| P3 | 二次精确识别（Parakeet）调优 | 识别更准 | 中，需空闲 CPU | 下课后评测 |

| P1 | 界面改造：统一工具栏、字幕为主体、底部控制条、术语胶囊 | 更高级、更有质感 | 中 | ✅ 完成 |
